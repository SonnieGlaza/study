# Interior Telegram Bot (MVP Foundation)

Стартовый каркас Telegram-бота по ТЗ:
- тест личности (20 вопросов, inline-кнопки, сохранение прогресса, restart/skip),
- персональные рекомендации и экспорт результата в PDF,
- AI-визуализация по фото с выбором степени изменений,
- режим консультаций,
- RAG/интеграции (заглушки с интерфейсами),
- подписки/доступ через GetCourse (заглушка клиента),
- web-админка для управления инструкциями и материалами.

## Текущая архитектура

- `app/main.py` — запуск FastAPI + Telegram polling.
- `app/bot/handlers.py` — сценарии бота.
- `app/admin/api.py` — административные HTTP-эндпоинты.
- `app/models.py` — SQLAlchemy-модели.
- `app/services/*` — сервисный слой.

## Быстрый запуск

1. Создать и активировать venv.
2. Установить зависимости:
   ```bash
   pip install -e .
   ```
3. Скопировать конфиг:
   ```bash
   cp .env.example .env
   ```
4. Заполнить `TELEGRAM_TOKEN`.
5. Запустить:
   ```bash
   uvicorn app.main:app --reload
   ```
